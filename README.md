# Лабораторная работа №5
### Параллельное умножение матриц с использованием MPI на кластере «Сергей Королёв»

## Задание
Модифицировать программу лабораторной работы для параллельного выполнения с использованием технологии MPI и провести серию экспериментов на кластере.

**Требования:**
- Провести эксперименты с разным количеством процессов (1, 2, 4, 8)
- Провести эксперименты с разными размерами матриц (200, 400, 800, 1200, 1600, 2000)
- Исследовать влияние количества процессов на производительность
- Выполнить автоматизированную верификацию результатов

## Создание SLURM скрипта для запуска:
```cpp
#!/bin/bash
#SBATCH --job-name=matMulMPI
#SBATCH --time=10:00:00
#SBATCH --nodes=1
#SBATCH --ntasks-per-node=8
#SBATCH --partition=batch
#SBATCH --output=matMul_%j.out

module load intel/mpi4

 Компиляция
mpicxx -std=c++11 -O2 -o laba main.cpp functions.cpp

 Запуск
mpirun -np $SLURM_NTASKS ./laba
```
