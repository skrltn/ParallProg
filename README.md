## Задание
Модифицировать программу лабораторной работы для параллельного выполнения с использованием технологии MPI и провести серию экспериментов на кластере.

**Требования:**
- Провести эксперименты с разным количеством процессов (1, 2, 4, 8)
- Провести эксперименты с разными размерами матриц (200, 400, 800, 1200, 1600, 2000)
- Исследовать влияние количества процессов на производительность
- Выполнить автоматизированную верификацию результатов

## Анализ результатов

### Время выполнения
- На малых размерах (N=200-400) параллелизация не даёт выигрыша из-за накладных расходов на MPI-коммуникации.
- На больших размерах (N=1200-2000) параллелизация эффективна: время для N=2000 сокращается со 129.1 с (1 процесс) до 66.4 с (4 процесса) — ускорение в 1.94 раза.
- 8 процессов не дают существенного прироста по сравнению с 4 из-за ограничения 4 физическими ядрами.

### Производительность
- Максимальная производительность 2114 MFLOPS достигнута на 2 процессах для N=200.
- Для больших матриц (N=1200-2000) производительность стабилизируется на уровне 240-260 MFLOPS.

### Ускорение
- Максимальное ускорение 1.95× получено на 8 процессах для N=1200.
- Ускорение на 2 процессах (1.79× для N=1600) близко к теоретическому пределу 2.0×.

### Эффективность
- Наибольшая эффективность 89.5% достигнута на 2 процессах для N=1600.
- С ростом числа процессов эффективность снижается: 2p→89%, 4p→48%, 8p→22%.
