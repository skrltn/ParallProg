## Задание

Разработать программу на языке C++ для умножения двух квадратных матриц с использованием параллельных вычислений (OpenMP). Провести исследование зависимости времени выполнения и производительности от размера матрицы. Выполнить автоматизированную верификацию результатов с помощью Python (библиотека NumPy).

### Алгоритм

Умножение матриц выполняется по классическому алгоритму:
C[i][j] = Σ(k=0..n-1) A[i][k] × B[k][j]
**Вычислительная сложность:** O(N³)

### Вероятные причины падения производительности

1. **При N=200** достигается пик производительности — матрица полностью помещается в кэш-память L2/L3 процессора
2. **При N=400** матрица уже не влезает в кэш, начинаются промахи кэша → резкое падение на 58%
3. **При N≥800** матрица работает напрямую с оперативной памятью → дальнейшее падение связано с ограничением пропускной способности памяти
