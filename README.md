Задание
Разработать программу на языке C++ для умножения двух квадратных матриц с использованием параллельных вычислений (OpenMP). Провести исследование зависимости времени выполнения и производительности от размера матрицы. Выполнить автоматизированую верификацию результатов с помощью Python (библиотека NumPy).

Умножение матриц выполняется по классическому алгоритму: C[i][j] = Σ(k=0..n-1) A[i][k] * B[k][j]
Вычислительная сложность алгоритма: O(N³)

- При N=400 достигается пик производительности (кеш-память L2/L3)
- При N>800 матрица не помещается в кеш, начинаются промахи
- Дальнейшее падение связано с ограничением пропускной способности памяти
