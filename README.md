## 4. Выводы

В ходе выполнения лабораторной работы была разработана CUDA-версия программы для умножения квадратных матриц. Проведены эксперименты с 5 конфигурациями блоков (8×8, 16×8, 16×16, 32×16, 32×32) и 6 размерами матриц (от 200 до 2000).

Основные результаты:
CUDA-реализация показала огромное преимущество перед последовательной версией — ускорение достигает почти 3000 раз для больших матриц. Это объясняется массовым параллелизмом GPU, где тысячи потоков выполняют вычисления одновременно.
Лучшая конфигурация зависит от размера матрицы:
Для матриц 200×200 оптимальны блоки 16×8
Для матриц 400–1200 лучшие результаты дают блоки 16×16
Для матриц 1600–2000 эффективны блоки 8×8
Максимальная производительность (132 295 MFLOPS) достигнута на конфигурации 16×16 для матрицы 1200×1200.
Производительность растёт с увеличением размера матрицы до определённого предела (1200×1200), после чего незначительно снижается из-за ограничений видеопамяти.
